# Avalonia UI Hierarchical TreeDataGrid & Firebird DB Client (C# / .NET 10)

Высокопроизводительное кроссплатформенное Desktop-приложение на фреймворке Avalonia UI, реализующее динамический вывод сложных иерархических (древовидных) структур данных и спецификаций изделий из реляционной СУБД Firebird. 

Проект спроектирован в строгом соответствии с архитектурным паттерном MVVM и принципами SOLID.

## 🔥 Ключевые архитектурные особенности и паттерны

*   **Корпоративный MVVM (Clean Architecture):** Четкое разделение слоев на Models (бизнес-логика), Views (декларативный XAML интерфейс) и ViewModels (состояние и команды) с поддержкой реактивных привязок данных (Data Binding).
*   **Иерархический TreeDataGrid:** Реализован динамический вывод вложенных спецификаций (изделие -> узлы -> детали) с раскрывающимися списками. Управление данными развернуто через специализированные источники данных Avalonia (`HierarchicalTreeDataGridSource`), что обеспечивает ленивую загрузку и плавную отрисовку тяжелых деревьев.
*   **Слой данных и абстракций (Data & Services Layer):** Бизнес-логика изолирована от инфраструктуры баз данных через интерфейсы в папке `Abstractions` и сервисы `Services`. Это позволяет бесшовно менять СУБД без изменения слоя UI.
*   **Работа с СУБД Firebird:** Интегрировано взаимодействие с базой данных Firebird (3-й диалект SQL), включая обработку связанных таблиц, иерархических связей (Parent-Child) и оптимизацию SQL-запросов для быстрого построения объектов в памяти (.NET 10).
*   **Слабая связанность (Loose Coupling):** Внедрена система локализации зависимостей, управление жизненным циклом сервисов и фабричная сборка View-компонентов.

## 🛠 Технологический стек

*   **Язык:** C# (современные стандарты .NET 10)
*   **UI Фреймворк:** Avalonia UI (Кроссплатформенный XAML)
*   **Компонент:** Avalonia.Controls.TreeDataGrid
*   **СУБД:** Firebird DB (с поддержкой реляционных иерархий)
*   **Архитектурный шаблон:** MVVM, DI (Dependency Injection), Clean Architecture

## 📁 Структура компонентов проекта

*   `/Abstractions` — Интерфейсы репозиториев данных и сервисов базы данных, задающие строгий контракт для инфраструктурного слоя.
*   `/Data` — Реализация контекстов подключения к Firebird DB, маппинг сущностей и выполнение SQL-запросов.
*   `/Services` — Бизнес-сервисы приложения, отвечающие за обработку, фильтрацию и построение древовидных коллекций.
*   `/ViewModels` — Логика управления интерфейсом (включая `SpecificationsViewModel.cs`), обрабатывающая раскрытие узлов и команды пользователя.
*   `/Views` — Разметка окон (`.axaml`) с кастомными стилями и шаблонами ячеек для TreeDataGrid.
