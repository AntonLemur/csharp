Система управления заказами

Функциональность:
- регистрация и авторизация
- роли Admin / Manager / User
- корзина товаров
- оформление заказов
- заказы по телефону через менеджера
- workflow обработки заказов
- статусы заказов
- управление товарами

Технологии:
- ASP.NET Core MVC
- Entity Framework Core
- ASP.NET Identity
- Firebird
- Bootstrap
